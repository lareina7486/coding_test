# 코딩테스트 오답·실수 회고 템플릿

문제를 다시 푸는 것뿐 아니라 **왜 틀렸는지, 다음에는 어떻게 검증할지**를 기록합니다.
이 파일은 작성용 템플릿이며, 실제 문제를 풀거나 재제출했다는 기록이 아닙니다.

## 문제별 기록 양식

| 항목 | 기록 |
| --- | --- |
| 날짜 | YYYY-MM-DD |
| 플랫폼 / 문제 URL | 프로그래머스 · 링크 |
| 언어 | Python / JavaScript / SQL |
| 문제 유형 | 구현 / 문자열 / 배열 / 탐색 / 정렬 / SQL 등 |
| 실패 유형 | 오답 / 시간 초과 / 런타임 오류 / 접근 방식 오류 |
| 최초 가설 | 무엇을 잘못 가정했는가? |
| 최소 반례 | 입력과 기대 출력, 실제 출력 |
| 원인 | 조건 누락 / 인덱스 / 자료형 / 복잡도 / 경계값 등 |
| 수정 방법 | 수정한 코드의 핵심 원리 |
| 검증 | 직접 실행한 테스트와 결과 |
| 재복습 날짜 | YYYY-MM-DD |

## 제출 전에 확인할 반례

- 빈 입력이나 길이가 1인 입력을 허용하는가?
- 중복 값, 음수, 0, 정렬 여부를 확인했는가?
- 입력 범위가 커질 때 시간·공간 복잡도가 적절한가?
- Python에서 `//`와 `/`, 가변 객체, 리스트 복사 등을 혼동하지 않았는가?
- SQL이라면 `NULL`, 중복 행, 정렬 순서와 JOIN 카디널리티를 확인했는가?

> **원칙:** 테스트하지 않은 코드를 통과했다고 기록하지 않고, 실행 결과와 추측을 구분합니다.
