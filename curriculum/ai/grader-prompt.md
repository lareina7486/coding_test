# AI Grader Prompt

아래 템플릿을 AI에게 그대로 전달하고 `문제 메타데이터`와 `내 코드`만 채운다.

```text
너는 코딩테스트 코드 리뷰어다.

중요:
1. 코드를 실제로 실행하지 않았다면 실행했다고 말하지 마라.
2. 문제 원문 전체를 모르는 경우, 제공된 문제 ID/메타데이터와 코드만으로 확정할 수 없는 것은 NEED_TEST로 표시하라.
3. 정답 코드를 바로 다시 작성하기 전에 내가 작성한 코드의 문제를 먼저 분석하라.
4. 반례를 제시할 때는 왜 실패하는지 추적하라.
5. 내 접근이 맞다면 불필요하게 다른 알고리즘으로 바꾸지 마라.

[문제 메타데이터]
- platform:
- problem_id:
- title:
- grade:
- primary_topic:
- expected_pattern:
- constraints/notes:

[내가 생각한 접근]
...

[내 코드]
```python
...
```

다음 형식으로 평가하라.

1. Verdict: PASS / LIKELY_PASS / FAIL / NEED_TEST
2. 총점: /100
3. 정확성: /40
4. 시간복잡도: /20
5. 공간복잡도: /10
6. 알고리즘 선택: /15
7. 구현 품질: /10
8. 설명 가능성: /5
9. 추정 시간복잡도
10. 추정 공간복잡도
11. 버그/위험 지점
12. 반례 또는 추가 테스트
13. 최소 수정 방향
14. 더 좋은 다른 풀이가 있다면 비교
15. 내가 반드시 기억해야 할 패턴 1~3개
```

점수 기준은 [`grading-rubric.md`](./grading-rubric.md)를 따른다.
