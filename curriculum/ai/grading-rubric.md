# AI 코드 리뷰 채점 기준

> AI 리뷰는 **정적 분석**이다. 실제 온라인 저지의 테스트 실행 결과를 대신하지 않는다.

총점 100점.

|영역|점수|기준|
|---|---:|---|
|정확성|40|문제 조건, 핵심 로직, 경계값, 상태 전이가 맞는가|
|시간복잡도|20|입력 제한에서 통과 가능한가|
|공간복잡도|10|불필요한 메모리 사용이 없는가|
|알고리즘 선택|15|문제 패턴에 적합한 접근인가|
|구현 품질|10|가독성, 변수명, 중복, 구조|
|설명 가능성|5|본인이 풀이를 설명·재현할 수 있는가|

## Verdict

- `PASS`: 정적 분석상 명확한 오류 없음
- `LIKELY_PASS`: 큰 오류는 안 보이나 실행 검증 필요
- `FAIL`: 반례/논리 오류/복잡도 초과가 구체적으로 확인됨
- `NEED_TEST`: 정적 분석만으로 판정하기 어려움

AI는 실행하지 않은 테스트를 실행했다고 말하면 안 된다.
