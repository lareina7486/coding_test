### 배운 개념

- 273710: ROOT 아이템은 부모가 없는 아이템. `PARENT_ITEM_ID IS NULL` 검사, `ITEM_ID`로 JOIN, ID 오름차순 정렬.
- 164671: `FROM (SELECT ... ORDER BY VIEWS DESC LIMIT 1) AS board` 파생 테이블로 최고 조회수 게시글 **하나를 먼저 선택**한 다음 `USED_GOODS_FILE`과 `BOARD_ID`로 JOIN하여 **모든 파일**을 조회. `CONCAT`으로 경로를 만들고 `FILE_ID DESC` 정렬.
- `LIMIT 1`은 파일 조회 결과가 아니라 **게시물 선택 서브쿼리** 안에서 적용해야 함.
- `SELECT *`는 사용자 원본대로 저장. 필요 컬럼만 선택하는 개선은 별도 조언이며 이 파일에는 반영하지 않음.
