- 현재는 **2그룹의 151141**에서 3개 테이블 다중 JOIN과 할인 정책 개념을 배웠고 **SQL은 아직 제출하지 않음**.

## 운영 규칙

1. 맞기 전에는 정답 SQL 비공개. 틀리면 **힌트 한 개씩** 제공.
2. 정답을 맞히면 다른 풀이 2~3개를 함께 비교하고 장단점 설명.
3. 매 풀이 후 남은 유형과 문제 **전체 목록**을 표시.
4. 플랫폼 통과, 코드 검토 정답, 오답, 미제출을 **별도 상태**로 관리.
5. 직접 작성한 사용자 SQL만 원문으로 저장. 묶음 완료 시 GitHub 일괄 커밋, 단 명시적인 전체 기록 동기화는 예외.
6. 미완료·보류는 유지한 채 같은 유형의 쉬운 문제부터 진행.
